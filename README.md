# Basalt tap

A Homebrew tap for [Basalt](https://basaltformac.com), a native macOS PDF
toolkit: eighteen document tools in one window, with redaction that destroys
content and verifies it is gone before writing the file.

```sh
brew install --cask chipmunk1101/tap/basalt
```

The installer is Developer ID signed, notarized and stapled by Caretopia Network
Private Limited, and the cask's checksum is taken from the published package.
