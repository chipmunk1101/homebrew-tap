# Homebrew tap

Casks for two Mac apps. Each installer is Developer ID signed, notarized and
stapled by Caretopia Network Private Limited, and each cask's checksum is taken
from the published package.

## Basalt

[Basalt](https://basaltformac.com) is a native macOS PDF toolkit: eighteen
document tools in one window, with redaction that destroys content and verifies
it is gone before writing the file.

```sh
brew install --cask chipmunk1101/tap/basalt
```

## Crumb

[Crumb](https://cleanwithcrumb.com) is a storage cleaner that explains what is
filling your disk and whether each item is safe to delete, then removes only
what you approve. Separate builds for Apple silicon and Intel; Homebrew picks
the right one.

```sh
brew install --cask chipmunk1101/tap/crumb
```
